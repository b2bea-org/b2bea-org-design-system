Disclosure · Accordion

Native <details>/<summary> with .b2bea-accordion chrome. Zero JS; keyboard space/enter to toggle. Chevron rotates via the [open] selector.

What's included with practitioner membership?
Directory access, member-only events, benchmarks, the academy library, and direct introductions to other practitioners in your domain.
Can vendors join the directory?
Yes — vendor profiles are reviewed and listed in the directory. Members can reach out directly.
How do you verify practitioners?
Manual review of LinkedIn profile, company affiliation, and role. Average review time is 48 hours.

Navigation · Tabs

Pure-CSS radio-input tabs with position-based panel reveal (up to 6 tabs per group). Native keyboard arrow-key cycling. Documented limit: doesn't implement the full ARIA tabs pattern (roving tabindex, manual activation); markup is wire-compatible if you add a JS layer later.

Navigation · Breadcrumb & Pagination

Pure-CSS, no JS. Breadcrumb wraps in <nav aria-label="Breadcrumb">; current page uses aria-current="page". Pagination wraps in <nav aria-label="Pagination">; unavailable prev/next uses aria-disabled="true".

Feedback · Tooltip

Pure-CSS hover and focus-within. Documented limits: no touch (no hover event); screen-reader announcement requires aria-describedby on the trigger pointing at the bubble's id.

Feedback · Toast

CSS styling + aria-live="polite" region. Variants: default, success, warning, error. JS hookup contract (documented, not shipped): show = append to region; dismiss = remove from DOM; auto-hide = remove after N ms; queue = cap N visible at once.
