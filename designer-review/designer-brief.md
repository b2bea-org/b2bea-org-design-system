# Designer Brief

## Purpose

Refine the B2BEA.org Lovable-era design system so it can support a production rebuild across public pages, admin, member profiles, vendor portal, company workspace, academy, surveys, jobs, events, and custom resources.

The goal is not a brand reinvention. The goal is a hardened, consistent, flexible system that a small team can use repeatedly without every page feeling hand-built.

## Audience

B2BEA serves B2B ecommerce practitioners:

- Manufacturers.
- Distributors.
- Ecommerce leaders.
- Agencies and consultants.
- Vendors selling into the B2B ecommerce ecosystem.
- B2BEA internal operators managing content, vendors, members, academy, events, and careers.

The system should feel useful, credible, current, and efficient. It should avoid decorative SaaS gloss.

## What Should Stay

- B2BEA dark blue as the dominant brand color.
- Coral as an accent/conversion color.
- Official B2BEA logos only.
- Lovable-inspired blue page headers.
- Open Sans as the current Lovable-era font direction unless the designer proposes a stronger replacement.
- Restrained title scale for standard pages.
- Compact operational UI for admin/portal/workspace surfaces.

## What Can Change

- Exact type scale.
- Secondary palette.
- Spacing scale.
- Card density.
- Border/radius/elevation values.
- Button and pill styling.
- Table density.
- Form layout patterns.
- Search/filter layout.
- Empty/error/loading/success state treatments.
- Logo usage guidance, if consistent with official assets.

## What Bad Looks Like

- Every page feels like a one-off.
- Standard page titles are oversized.
- Admin and portal pages feel like marketing pages.
- Fields, pills, and filters have mixed styles.
- Cards are nested inside decorative cards.
- The site uses unofficial logo recreations.
- Design decisions work for a hero page but fail in dense tables/forms.
- Mobile layouts overlap, crop, or rely on tiny unreadable text.

## Required Outcome

The designer should return changes in a form that can update:

- `b2bea.css`
- `b2bea.design.json`
- `design-system.json`
- visual examples in `designer-review/`
- logo usage guidance
- component and state rules
